# Noor Al-Banat — Online Quran Learning Website

**Live Website:** [noor-al-banat.netlify.app](https://noor-al-banat.netlify.app/)

Noor Al-Banat is a responsive website for an online Quran learning initiative dedicated to helping girls strengthen their Islamic knowledge and spiritual connection. It presents available courses, introduces the platform’s vision and mission, and provides convenient contact options for prospective students.

## ✨ Features

- **Course Showcase:** Displays nine Islamic learning subjects with dedicated images and descriptions.
- **Quran Education:** Covers Quran recitation, Tajweed, Hifz, Noorani Qaida, and Quran translation and Tafseer.
- **Islamic Studies:** Includes Namaz, Ahadees, Masnoon Duas, and the Six Kalmas.
- **About Section:** Highlights the platform’s vision, mission, and educational values.
- **Responsive Navigation:** Provides convenient access to the main sections.
- **Contact Integration:** Includes WhatsApp, phone, and email links.
- **Animated UI:** Uses CSS animations and JavaScript for visual effects.
- **Visual Branding:** Features custom images, a logo, and a favicon.

## 🛠️ Technologies Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, layouts, and animations
- **JavaScript** — Interactive functionality
- **Bootstrap 4** — Responsive layout and navigation
- **jQuery** — JavaScript utilities and Bootstrap integration
- **Font Awesome** — Icons

## 🚀 Getting Started

### Prerequisites

A modern web browser and a code editor, such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/usmana0820/Quran-website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Quran-website
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No backend setup is required for the static website.
